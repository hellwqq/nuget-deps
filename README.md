# depgraph — визуализатор графа зависимостей NuGet

Конфигурационное управление, практическая работа № 2, вариант 24.

## 1. Общее описание

CLI-инструмент на Python 3 (только стандартная библиотека), который по
конфигурационному файлу INI получает зависимости пакета .NET (NuGet),
строит граф зависимостей и визуализирует его.

Статус: **этап 1** (конфигурация и вывод параметров).

## 2. Настройки (`config.ini`, секция `[settings]`)

| Параметр       | Описание                                              |
|----------------|-------------------------------------------------------|
| `package_name` | имя анализируемого пакета                             |
| `repository`   | URL репозитория или путь к файлу тестового репозитория |
| `test_mode`    | режим тестового репозитория (`true` / `false`)        |
| `version`      | версия пакета                                         |
| `output_file`  | имя файла с изображением графа (`*.png`)              |
| `ascii_tree`   | вывод зависимостей в виде ASCII-дерева                |
| `max_depth`    | максимальная глубина анализа (целое, >= 1)            |

Все параметры обязательны. Ошибки (нет файла, нет секции, пустое или
неверное значение) выводятся как `error: ...`, код возврата 1.

## 3. Сборка и тесты

Сборка не нужна. Тесты:

    make test

## 4. Запуск и примеры

    ./run.sh                      # config.ini по умолчанию
    ./run.sh -c my.ini

Пример вывода этапа 1:

    package_name = Newtonsoft.Json
    repository = https://api.nuget.org/v3/index.json
    test_mode = False
    version = 13.0.3
    output_file = graph.png
    ascii_tree = True
    max_depth = 3
